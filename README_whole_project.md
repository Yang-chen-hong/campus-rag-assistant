# 🎓 校园智能问答助手

基于 **LangChain + LangGraph + ChromaDB + Streamlit** 构建的校园 RAG 智能问答系统，支持多轮对话记忆、引用溯源和业务 Skills 工具调用。


## 📌 项目简介

本项目是一个面向高校场景的智能问答助手，能够基于学校官方文档（规章制度、专业介绍、新闻通知等）为学生提供准确、可溯源的问答服务。

### 核心能力

| 功能 | 说明 |
| :--- | :--- |
| 📚 **RAG 检索增强** | 基于 3521 条校园文档分片，通过 BGE-M3 向量检索实现精准召回 |
| 🧠 **Agent 自主决策** | 基于 LangGraph 构建，支持意图识别、分支路由、多轮对话 |
| 🔗 **引用溯源** | 每个回答都标注来源，支持「来源：编号」和「来源：Skill」双重溯源 |
| 🛠️ **Skills 工具调用** | 集成奖学金查询、处分查询、政策时效查询等业务工具 |
| 💬 **多轮对话记忆** | 支持上下文理解，能够记住历史对话并正确理解代词指代 |
| 🌐 **Web 交互界面** | 基于 Streamlit 构建，支持思考过程可视化 |

## 🚀 快速开始

### 1. 环境要求

- Python 3.10+
- Conda（推荐）

### 2. 克隆项目

```bash
git clone <你的仓库地址>
cd campus_rag
```

### 3. 创建虚拟环境

```bash
conda create -n agent_env python=3.11
conda activate agent_env
```

### 4. 安装依赖

```bash
pip install streamlit langchain langchain-community langgraph chromadb sentence-transformers jsonlines python-dotenv zhipuai
```

### 5. 配置 API Key

在项目根目录创建 `.env` 文件，填入你的智谱 API Key：

```properties
ZHIPU_API_KEY="你的智谱API_Key"
```

### 6. 启动应用

```bash
streamlit run app.py
```

浏览器打开 `http://localhost:8501` 即可使用。


## 🎯 使用示例

### 示例 1：政策类问答

```
👤 用户：一等奖学金的条件是什么？

🤖 助手：根据【奖学金评定办法第四条】，一等奖学金要求：
- 无挂科记录
- 平均绩点 3.5 以上
- 无违纪处分记录

【来源：1】
```

### 示例 2：多轮对话

```
👤 用户：一等奖学金的条件是什么？
🤖 助手：要求无挂科、绩点 3.5 以上...

👤 用户：那我挂了一科，符合吗？
🤖 助手：根据您之前问的一等奖学金条件，挂科不符合要求。
```

### 示例 3：Skills 工具调用

```
👤 用户：我大二，绩点3.2，没有处分，能申请什么奖学金？

🤖 助手：根据 Skills 工具查询结果：
- ✅ 符合二等奖学金申请条件（要求：挂科≤1门、无处分、绩点≥3.0）
- 建议同时关注单项奖学金和进步奖

【来源：Skill】
```
